How to apply it

Most built-in home screens (Motorola, Samsung, Pixel) do not load icon packs, so use a launcher that does.

  1. Install a launcher that supports icon packs, for example Lawnchair (free and close to the stock look) or Nova, and make it your home app.
  2. Install iconX with the button above or from Ash Store.
  3. Open iconX, go to Apply and tap Apply next to your launcher. Nova and Smart Launcher switch at once; other launchers open so you can finish there.
  4. Or in your launcher: Settings, then Icon pack (or Icon style), then iconX.
